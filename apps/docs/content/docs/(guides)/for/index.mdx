Plotra is one app with many tools, and nobody needs all of them. These pages are routes through it. Each one is written for one kind of person and says what Plotra does for them, how to set a project up for that work, a workflow from the first project to the finished thing, and which pages of the documentation to read next.

They describe no feature that isn't documented elsewhere. For the details, follow the links into the rest of these docs: [Modules](/docs/modules) and [Project types](/docs/reference/project-types) are the two you will use most.

## By project type

A project's type is a preset: it decides which modules start switched on, what format a new scene is written in and what a release is called. It locks nothing, so the page for your type is a starting point, not a fence. The types are described in full on [Project types](/docs/reference/project-types).

| Project type | Starts with | A release is a | Read |
| --- | --- | --- | --- |
| **Novel / series** | The essentials | Book | [Novelists](/docs/for/novelists) |
| **Web serial** | The essentials | Chapter | [Novelists](/docs/for/novelists) |
| **Short story** | The essentials | Other | [Novelists](/docs/for/novelists) |
| **Tabletop RPG** | World bible, Releases & reveals | Session | [Game masters](/docs/for/game-masters) |
| **Screenplay / TV** | Script formats | Episode | [Screenwriters](/docs/for/screenwriters) |
| **Stage play** | Script formats | Other | [Screenwriters](/docs/for/screenwriters) |
| **Comic / manga** | Script formats | Issue | [Screenwriters](/docs/for/screenwriters) |
| **Podcast / audio drama** | Script formats | Episode | [Screenwriters](/docs/for/screenwriters) |
| **Game / interactive** | Interactive narrative | Patch | [Game writers](/docs/for/game-writers) |
| **Non-fiction / research** | Research & sources | Book | [Non-fiction and research](/docs/for/nonfiction) |
| **Franchise / IP bible** | World bible | Book | [Teams](/docs/for/teams) |

"The essentials" means no module at all: the editor, the binder, links and the views that are always there.

## By role in a project

If someone else owns the project, your page depends on what you were given.

| You are | You can | Read |
| --- | --- | --- |
| A workspace **owner** or **admin** | Everything in every project, plus members, sharing and settings. Owners also manage the plan. | [Workspace owners](/docs/for/workspace-owners) |
| A workspace **member** | Read, comment and edit in every project of the workspace, and create projects | [Teams](/docs/for/teams) |
| An **editor** on one project | Read, comment and edit in that project | [Collaborators](/docs/for/collaborators) |
| A **commenter** on one project | Read and comment | [Collaborators](/docs/for/collaborators) |
| A **viewer** on one project | Read | [Collaborators](/docs/for/collaborators) |
| A visitor with a **read-only link** | Read, without an account | [Collaborators](/docs/for/collaborators#reading-through-a-read-only-link) |

The full matrix is on [Roles and permissions](/docs/reference/roles-and-permissions).

## Things to know

- Every view and module is on both plans of the hosted version. The Free plan limits room, not features: 10 projects, 50 MB of storage, 3 workspace members and 5 people on each shared project. See [Plans and billing](/docs/settings/plans).
- New to all of it? Start with [Your first project](/docs/get-started), which takes you from signing up to your first scene.
