Your writing is yours to move. Bring a book that is already under way into Plotra, and take it out again at any time in a file other programs can open. Export is never held back by a plan limit.

## Out and back in

A [Plotra project file](/docs/import-export/import#plotra-project-files) brings back nearly everything, as a new project. The other formats don't: exporting and importing again is not a backup of everything. This is what a round trip through **Markdown, a file per note** keeps:

| Kept | Lost |
| --- | --- |
| The text and its formatting | Each note's type: imported notes become notes or scenes, whichever you choose, and folders |
| The folder structure and the order of notes | Properties, synopsis, status, label and aliases |
| Titles and tags | Canon status, reveal tags and block tags |
| Links between notes, and embeds | Comments, suggestions and version history |
| Web links, tables, lists, callouts | Canvases, timelines and dialogue trees |
| | Uploaded images and attached files |
| | Citations: they come back as plain text |

Choose **One note per file** and **Keep single line breaks** when importing such a zip (unzip it and choose the folder; both are chosen for you).

A single Markdown file comes back as chapters and scenes with **Split at headings**. Word and plain text come back without links, and their scenes come back as separate notes only with **Start a new scene at every scene break** on. Plain text keeps its chapters only when their titles read like "Chapter 1" or "Prologue".

Other tools have their own exports, described on their pages: [Fountain](/docs/modules/scripts) for scripts, [Interactive narrative](/docs/modules/interactive) for Ink, Yarn and Twine, [Localization](/docs/modules/localization) for translators' files, and [Publishing](/docs/modules/publishing) for EPUB, the series bible and the public wiki.

## Who can import and export

| Action | Who |
| --- | --- |
| Export, and print to PDF | Anyone signed in who can read the project: viewers, commenters, editors and up. You get only the notes you can read. |
| Import | Anyone who can edit the folder the notes go into, or the project when they go to the top of the binder. |

For people who can't edit, **Import…** is missing from the **New…** menu and **All commands**, and greyed out in the right-click menu.

Someone reading through a [read-only link](/docs/collaboration/sharing#read-only-links) has no account and can't export.

Both dialogs need a connection: files are read and built on the server.

**Export is never blocked by a plan limit.** A workspace that is over its limits can still export everything. See [Quotas](/docs/settings/limits).
