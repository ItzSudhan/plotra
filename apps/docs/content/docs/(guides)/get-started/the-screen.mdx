Every project opens on the same screen. This page names its parts, so the rest of the docs can say "the inspector" or "the ribbon" and you know where to look.

![A project open on a scene: the ribbon on the left, then the binder, the scene in the middle, the inspector on the right and the status bar along the bottom](/shots/screen.webp)

From left to right:

| Part | What it is |
| --- | --- |
| **Ribbon** | A strip of buttons. Each view button opens a view: graph, codex, outline and so on. See [The ribbon](#the-ribbon). |
| **Binder** | The tree of everything in the project, with a **Tags** tab beside it. See [The binder](/docs/writing/binder). |
| **Panes** | The middle. Notes and views open here as tabs. You can split a pane right or down and drag tabs between panes. With nothing open, it shows the [project home](#the-project-home). |
| **Inspector** | The right sidebar, about the note that is open. It stays closed until you open a note. Its tabs are **Note** (Properties and Outline), **Links**, **Story** and **Review** (Comments and History). Story is there when the World bible, Releases & reveals or Research module is on, and an **AI** tab when the AI agent is. |
| **Status bar** | Along the bottom: the words in the open note, the words you have typed this session, whether your changes are saved, who else is here, notifications and your account menu. More can be switched on. |

Drag the edge of the binder or the inspector to resize it, from 200 to 520 pixels. You can also `Tab` to the edge and move it with `←` and `→`. The widths are remembered in your browser.

On a phone or a narrow window, the binder and the inspector open over the page as drawers, and the ribbon becomes a bar across the top:

| Button | What it does |
| --- | --- |
| **Open binder** | The binder, as a drawer from the left. |
| The project's title | |
| **Find a note** | Find a note by name. |
| The bell | Your notifications. |
| **Views and commands** | Your ribbon's views, each with a line on what it is for, then **More views…**, **All commands**, **Project settings** and **Keyboard shortcuts**. |
| **Open details** | The inspector, as a drawer from the right. |

Tap outside a drawer, or press `Esc`, to close it.

## The ribbon

From top to bottom:

| Button | What it does |
| --- | --- |
| Arrow | Back to the workspace's projects, or to "Shared with you" if you are a guest. |
| **Show the binder** / **Hide the binder** | Shows or hides the binder (`⌘\`). |
| **Find a note** | Jump to a note by name (`⌘O`). |
| **All commands** | Every command, searchable (`⌘P`). |
| The views | A few views, each with its name under the icon. Point at one to see what it is for. |
| **More** | Every other view, and the settings below. |
| **Project settings** | Opens the [project settings](/docs/settings/project). |
| **Show the inspector** / **Hide the inspector** | Shows or hides the inspector (`⌘⇧\`). |

A project has twenty or more views. The ribbon starts with five, chosen by how the project was started, and the rest are under **More**. From there the ribbon is yours: right-click a view for **Move up**, **Move down**, **Remove from ribbon** and **Customize…**. If you chose **Show every view** in Customize, right-click offers **Show only your ribbon's views** instead. Your arrangement is saved with your account, so it is the same in every project and on every device, and nobody else's ribbon changes. See [Customising the ribbon](/docs/settings/customize#the-ribbon).

### The More menu

| Section | What is in it |
| --- | --- |
| Views | Every view that is not in your ribbon, grouped as **Plan**, **World**, **Read and publish**, **Team and progress** and **Tools**, each with a line on what it is for and its shortcut. |
| **More tools** | The tools this project has not switched on. Choosing one opens the prompt described below. Only people who manage the project see it. |
| **Modes**: **Saved layouts** | Switch between saved arrangements of panes (`⌘⇧L`). |
| **Focus mode** | Hides everything but the active pane (`⌘⇧F`). Escape leaves. |
| **Keep on this device, for offline** | Fetches every note of the project into this browser, so it all opens offline. Ticked while the project is kept. See [Keeping a whole project on this device](/docs/writing/editor#keeping-a-whole-project-on-this-device). |
| **Typewriter scrolling** | Keeps the line you are writing in the middle of the screen (`⌘⌥⇧T`). |
| **Settings**: **Keyboard shortcuts** | The list of shortcuts (`⌘/`). |
| **Customize…** | The ribbon, the inspector, the look of the page, the interface size, the project home and the guidance. |

![The More menu open from the ribbon, listing views under Plan, World, Read and publish, and Team and progress, then More tools, Saved layouts and Focus mode](/shots/ribbon-more.webp)

## The project home

When no note is open, the panes show the project's title, its word count and four blocks:

| Block | What it shows |
| --- | --- |
| **Carry on** | The four notes changed most recently, with their word counts. In an empty project: **Write the first scene**, or "Nothing has been written here yet." for someone who can't edit. |
| **This session** | Words typed this sitting, against your session goal if you have one. Without one, **Set a goal for each sitting** opens the Stats view. See [Writing goals](/docs/writing/goals). |
| **Next, when you want it** | The next step of the checklist, with **Show me where** or **Turn on …**. Gone once the checklist is finished or closed. |
| Shortcuts | A button for the project's main type of note, such as **New scene** or **New session** (for people who can edit), **Open a note**, **All commands**, and **Writing stats and goals**. |

![The project home with no note open: the title and word count, Carry on, This session and the shortcuts](/shots/project-home.webp)

Choose which blocks are shown, and their order, under **Customize… → Project home**.

## Tabs and panes

Notes and views open as tabs in the middle of the screen.

![Two panes side by side: the scene The Balcony on the left and the corkboard of its chapter on the right](/shots/panes-split.webp)

| Keys | What it does |
| --- | --- |
| `⌘⌥\` | Split the pane to the right |
| `⌘⌥→` / `⌘⌥←` | Next and previous tab |
| `⌥W` | Close the tab |
| `⌘⇧M` | Make the pane fill the window, and back |

**All commands** has three more that have no keys to begin with: **Split down**, **Pin or unpin tab** and **Close all tabs**.

- **Splitting** moves the active tab into a new pane, so the pane needs at least two tabs.
- Drag a tab to another pane, or to the edge of one to make a new split.
- Middle-click a tab to close it.
- **A pinned tab** stays open: opening another note from the binder goes beside it instead of replacing it. It shows a pin where the close button was. Unpin it, or use `⌥W`, to close it.
- Coloured dots on a tab are the other people who have that note open. A single dot in place of the close button means the note has changes that haven't reached the server yet; see [Saving and working offline](/docs/writing/editor#saving-and-working-offline).

On a phone-sized screen there is one pane at a time; the splits come back when there is room. The binder and the inspector open over the page as drawers, and the ribbon becomes a bar across the top.

### Saved layouts

Your open tabs and splits are remembered per project in your browser, along with which tabs are pinned. To keep more than one arrangement, for example "Drafting" and "Plotting", save it as a **layout**.

1. Press `⌘⇧L`, or choose **Saved layouts** under **More** in the ribbon.
2. Type a name and press `Enter` to save the current arrangement. Typing the name of a layout you already have replaces it.
3. To switch, open the list again and pick one. The bin icon on a row deletes it.

Saved layouts are stored with your account, per project, so they follow you to another computer and nobody else sees them. A name can be 60 characters. When a layout is opened, tabs for notes that have since been trashed or deleted are left out.

## The inspector

The inspector is the sidebar on the right. It is about the note in the active tab. Show or hide it with `⌘⇧\`.

It starts closed, so a project opens calm. The first time you open a note, it opens on the note's properties; after that it stays as you leave it. On a phone it is called **Details**.

| Tab | Panels | What is in it |
| --- | --- | --- |
| **Note** | **Properties**, **Outline** | The note's fields, and its headings. Click a heading in the outline to jump to it. |
| **Links** | | **Mentioned in**, **This note links to** and **Named but not linked**. `⌘⌥⇧B` opens it. See [Mentioned in](/docs/writing/links#mentioned-in). |
| **Story** | | Canon status and reveals. Only when **World bible**, **Releases & reveals** or **Research & sources** is on. See [Canon](/docs/canon#canon-status). |
| **Review** | **Comments**, **History** | Comment threads and suggestions, and saved versions. See [Working together](/docs/collaboration/comments-and-suggestions#comments). |
| **Chat** | | The project's chat, or the open note's. See [Chat](/docs/collaboration/chat). |
| **AI** | | The AI chat. Only where AI is on. See [AI](/docs/ai). |

The gear at the right of the tabs opens **Customize**, where you can give each panel a tab of its own, hide panels and change their order.

## The status bar

The bar along the bottom of the window, from left to right:

| Item | What it is |
| --- | --- |
| Workspace / project | Where you are. Off to begin with. |
| **World as of …** | Shown while a spoiler horizon is on. Click the name to open the release roadmap, or the cross to show the whole world. |
| **words in the project** | Every note outside the trash, as last saved. Off to begin with. |
| **words** · **characters (with spaces)** | The note in the active tab. The character count is off to begin with. |
| **this session** | Words typed this sitting, against your session goal. Click for stats and goals. |
| **Saved**, **Saving…** or **Offline — changes kept on this device** | Whether your changes have been saved. |
| Avatars | The other people in the project right now. Point at one to see which note they are in; click to open it. |
| The bell | Your notifications. See [Notifications](/docs/collaboration/notifications). |
| Your avatar | The user menu. |

A new project's bar is kept quiet: the workspace and project, the words in the project and the character count start switched off. Switch any item on or off, or move it, in **Customize** → **Status bar**, except your avatar, which stays last. **Offline** shows even when you took the saving state off, so you always know when changes haven't been saved. The list there also has a **Space**: what's above it sits on the left of the bar, what's below it on the right.

The counts and the sync states are explained on [The editor](/docs/writing/editor#word-counts).

### The user menu

Click your avatar at the right of the status bar.

| Item | What it does |
| --- | --- |
| **Theme** | Light, Dark or System. |
| **Your settings** | Opens your account settings. See [Your account](/docs/settings/account). |
| **Keyboard shortcuts** | Opens the shortcuts list (`⌘/`). |
| **Getting started** | Brings back the checklist, if you closed it. In a sample, it is called **Try it: fix the mistake**. |
| **Join the Discord** | Opens Plotra's Discord server in a new tab. |
| **Report a bug** | **By email**, **On Discord** or **On GitHub (needs an account)**. The email and the GitHub report come with your browser and Plotra's version already filled in. Nothing from your project is sent. |
| **Sponsor Plotra** | Opens the project's sponsorship page. Sponsoring buys nothing in the app. |
| **Sign out** | |

## Find anything

| Keys | What it does |
| --- | --- |
| `⌘O` | Find a note: jump to a note by name |
| `⌘⇧O` | Search the whole project |
| `⌘P` | All commands: every command, searchable |
| `⌘/` | The list of keyboard shortcuts, where you can change them |
| `⌘\` | Show or hide the binder |
| `⌘⇧\` | Show or hide the inspector |

On Windows and Linux, use `Ctrl` where these docs say `⌘`. Changed shortcuts are stored with your account, so they follow you to every computer.

![All commands with "open" typed, listing the commands that open each view and their shortcuts](/shots/command-palette.webp)

### All commands

`⌘P` opens **All commands**: every command in the project, grouped, with its shortcut. Type to filter, `↑` `↓` to move, `↵` to run, `Esc` to close. Commands that belong to a tool are only listed while it is on. Commands about the open note name it by its type: "Rename this chapter". The full list is on [Keyboard shortcuts](/docs/reference/keyboard-shortcuts).

### Find a note

`⌘O` opens **Find a note**. Type part of a note's name, or of a folder it is in.

![Find a note with "ju" typed, offering Juliet Capulet and two secrets, and a row to create a note with that name](/shots/quick-switcher.webp)

| Keys | What it does |
| --- | --- |
| `↵` | Open the note in the current tab |
| `⌘↵` | Open it in a new tab |
| `⌘⌥↵` | Open it to the right |

If nothing has exactly the name you typed, the last row offers to **Create** one with it: the project's main type of note, a scene in a novel or a session in a campaign, as `⌘⌥N` makes. Folders are not listed.

`⌘⇧O` searches the text of every note instead of the names.
