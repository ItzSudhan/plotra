---
title: Glossary
description: "Every term Plotra and these docs use, in alphabetical order, with a link to the page that covers it."
---

Plotra has its own words for things, and a few words that mean two things depending on where you are. This page lists them all. Each entry says what the term means in one or two sentences and links to the page that covers it.

The terms are written as the interface writes them. Where the interface or the docs use two words for one thing, the entry says so.

## A

| Term | What it means |
| --- | --- |
| **Accent colour** | The colour of buttons, focus rings, the active tab and highlights: Ember to begin with. Set in **Customize → Colours**. See [Colours and your own CSS](/docs/settings/customize#colours-and-your-own-css). |
| **Access key** | What the GitHub tab of the project settings calls the key you paste from GitHub so Plotra can write to your repository (GitHub calls it a token). See [A copy kept in GitHub](/docs/import-export/export#a-copy-kept-in-github). |
| **Action** | One of the five things a role may do in a project: read, comment, edit, delete and manage. Every permission check comes down to one of them. In a script, **Action** is also the element for what is seen and done. See [The five actions](/docs/reference/roles-and-permissions#the-five-actions). |
| **Activity** | The view that lists what happened in a project and who did it, newest first. The docs also call it the activity feed. See [The activity feed](/docs/collaboration/notifications#the-activity-feed). |
| **Admin** | A workspace role. An admin can do everything a member can, and also manages each project's settings and sharing, the workspace's members and its settings, but not its AI switch, its plan or deleting it. See [Members](/docs/settings/account#members). |
| **Agent** | The AI assistant that works inside a project as you, with your permissions. It is off until the workspace and the project both switch it on. The module is called **AI agent**. It works through tools, such as **Read the shared world**, and checks continuity and spoilers after each change it makes. See [The AI agent](/docs/ai), [What the agent can do](/docs/ai#what-the-agent-can-do) and [Checks after each change](/docs/ai#checks-after-each-change). |
| **Alias** | Another name a note goes by. Links, the link picker and **Named but not linked** match aliases as well as titles. See [The Properties panel](/docs/writing/properties-and-tags#the-properties-panel). |
| **All commands** | The searchable list of every command in the project, opened with `⌘P`. It used to be called the command palette. See [All commands](/docs/get-started/the-screen#all-commands). |
| **API token** | A key starting with `plt_` that lets a script, an automation or an AI assistant use Plotra as you, through the REST API or MCP. Made in **Your settings**, under **Advanced**. See [API tokens](/docs/developers/api#api-tokens). |
| **Approval** | A tick on a workflow stage. A note can only enter that stage once every required reviewer has approved it. See [Workflow](/docs/settings/project#workflow). |
| **Approve as manager** | Approving a note in place of its required reviewers, which people who manage the project can do. See [Approve as manager](/docs/modules/editorial#approve-as-manager). |
| **Approver** | Someone who may change a locked note or move it out of its locked stage: the note's required reviewers, and the people who manage the project. See [Locked content](/docs/modules/editorial#locked-content). |
| **Attachment** | A file attached to a research note: a PDF, a scan, a photograph. The interface lists them under **Files**. See [Attachments and files](/docs/modules/research#attachments-and-files). |

## B

| Term | What it means |
| --- | --- |
| **Backlink** | The old name for **Mentioned in**. |
| **Beat sheet** | A story structure (Save the Cat, Hero's Journey, Story Circle, a romance or a mystery, a TV episode, a five-room dungeon, or one you saved yourself) laid out as a folder of chapters and scenes for you to fill in. See [Starting from a structure](/docs/writing/binder#starting-from-a-structure). |
| **Beta reader** | Someone a project is shared with to read, or to read and comment, without being able to edit. A beta reader is an ordinary project share with the viewer or commenter role. See [Beta readers](/docs/modules/editorial#beta-readers). |
| **Bibliography** | Every source in the project as a reference list, in the project's citation style. It is the Sources view, and can be downloaded as Markdown, plain text or BibTeX. See [The bibliography](/docs/modules/research#the-bibliography). |
| **Binder** | The tree on the left that holds every note in the project. See [Working in the binder](/docs/writing/binder#working-in-the-binder). |
| **Block** | One piece of a note's text: a paragraph, a heading, a list item, a table, an image. See [Blocks](/docs/writing/editor#blocks). |
| **Block selection** | One or more whole blocks selected by clicking the handle in the margin, which the keys then move, copy, duplicate or delete together. See [Moving blocks](/docs/writing/editor#moving-blocks). |
| **Block tag** | Settings on one block that differ from its note: its own canon status, its own reveal, a knowledge layer, a fact-check status. The docs also say "tagged passage", which is the name of the list in the Story tab. See [Block tags](/docs/canon/releases-and-reveals#block-tags). |
| **Breakdown** | The Production view's list of what each scene of a script needs: cast, props, wardrobe and the other categories. A breakdown tag marks the words that name such an element. See [Script breakdown](/docs/modules/production#script-breakdown). |

## C

| Term | What it means |
| --- | --- |
| **Calendar** | How a timeline reads dates. A timeline uses the Gregorian calendar until you give it one of your own, with its own months, day length and eras. See [Calendars](/docs/views/timeline-and-canvas#calendars). |
| **Call card** | A dialogue card that plays a shared branch and comes back when the branch reaches a **Return** card. See [The nine kinds of card](/docs/modules/interactive/dialogue#the-nine-kinds-of-card). |
| **Canon status** | Whether a note is part of the story's continuity: Canon, Draft, Speculative, Retconned or Non-canon. A new note is Draft. See [Canon status](/docs/canon#canon-status). |
| **Canvas** | A kind of note that opens as an endless board for arranging cards by hand. The docs also call it a storyboard, and the read-only link calls it a board. See [Canvas](/docs/views/timeline-and-canvas#canvas). |
| **Card** | Three things, by view. On the Corkboard, a note shown as an index card. On a canvas, a note card, a text card, an image or shot panel, or a group. In a dialogue, one step of the conversation: Start, Line, Choice, Condition, Set, Random, Call, Return or End. See [Corkboard](/docs/views/planning#a-card), [Kinds of card](/docs/views/timeline-and-canvas#kinds-of-card) and [The nine kinds of card](/docs/modules/interactive/dialogue#the-nine-kinds-of-card). |
| **Changelog** | A tab of the Reviews view that lists what was added, changed, removed and retconned since a release was cut. See [The changelog per release](/docs/modules/editorial#the-changelog-per-release). |
| **Channel** | Where the audience learns something: the main text, a trailer, an interview. Channels are labels for planning and do not change what the spoiler horizon hides. The settings call them **Reveal channels**. See [Channels](/docs/canon/releases-and-reveals#channels). |
| **Chapter** | A kind of note that groups scenes. A project can call it something else, such as "Session" or "Sequence". See [Note types](/docs/writing/binder#note-types). |
| **Chat** | Talk beside the page that isn't anchored to words: one chat for the whole project and one for each note. Anyone who can comment can write in it. See [Chat](/docs/collaboration/chat). |
| **Citation** | A reference to a research note placed in the text by typing `[@`. It is shown in the project's citation style and follows the source when its details change. See [Citations in the editor](/docs/modules/research#citations-in-the-editor). |
| **Claim** | A block marked for fact-checking. See **Fact-check**. |
| **Clip** | A web page saved as a research note, with the details the page gives about itself filled in. See [Clipping a web page](/docs/modules/research#clipping-a-web-page). |
| **Codex** | The view that lets you read characters, locations and other world pages like a wiki, grouped by type. See [Codex](/docs/views/world#codex). |
| **Cold open** | The set of questions at `/start` that builds a first project from your answers. See [The cold open](/docs/get-started/first-project#the-cold-open). |
| **Command palette** | The old name for **All commands**. |
| **Comment** | A remark on a passage or on a whole note, kept in a thread in the inspector. See [Comments](/docs/collaboration/comments-and-suggestions#comments). |
| **Commenter** | A project role. A commenter can read everything and comment, and cannot edit. See [The roles](/docs/reference/roles-and-permissions#the-roles). |
| **Condition** | A dialogue card that goes one way when its expression is true and another when it is false. See [Conditions](/docs/modules/interactive/expressions#conditions). |
| **Continuity check** | One of the plain rules the Continuity view runs over the project, such as "Appears after death" or "In two places at once". No AI is involved. See [Continuity checks](/docs/canon/secrets-and-continuity#continuity-checks). |
| **Continuity sheet** | A sheet built for one character: every scene they are in, their age then, where, and what they learn. The tab is called **Character sheets**. See [Continuity sheets](/docs/canon/secrets-and-continuity#continuity-sheets). |
| **Copy this project** | What readers of a read-only link can do when its managers allow it: copy the project into a workspace of their own, as a template. See [Letting readers copy it](/docs/collaboration/sharing#letting-readers-copy-it). |
| **Corkboard** | The view that shows the notes of one folder as index cards you can reorder. See [Corkboard](/docs/views/planning#corkboard). |
| **Credit** | The unit hosted AI is paid in on the Pro plan. One credit is 1,000 input tokens, and output tokens count five times. See [Hosted AI and credits](/docs/settings/plans#hosted-ai-and-credits). |
| **Customize** | The dialog that holds what is yours alone: your ribbon, your inspector, the look of the page, the project home and the guidance. See [Customize](/docs/settings/customize). |
| **Cut a release** | To snapshot every note as it stands, so the changelog can compare against it later. See [Cutting a release](/docs/modules/editorial#cutting-a-release). |

## D

| Term | What it means |
| --- | --- |
| **Default (project or workspace)** | Someone's Customize setup made the starting point for everyone in a project or a workspace who hasn't chosen their own. See [Defaults for a project or a workspace](/docs/settings/customize#defaults-for-a-project-or-a-workspace). |
| **Desktop app** | Plotra as an app on macOS, Windows or Linux: a window on Plotra Cloud, or a library on your own computer. See [The desktop app](/docs/desktop). |
| **Dialogue** | Two things. A kind of note that holds a branching conversation, which the docs also call a dialogue tree; it needs the Interactive narrative module. In a script, the element for what a character says. See [Dialogue notes](/docs/modules/interactive/dialogue#dialogue-notes) and [Writing in a script](/docs/modules/scripts#writing-in-a-script). |
| **Digest** | One email a day that lists the notifications you haven't read. It is the default email setting. See [The digest](/docs/collaboration/notifications#the-digest). |
| **Diplomacy web** | The Relationships map with factions or another entry type showing in place of characters, so it draws alliances and wars. See [A diplomacy web](/docs/views/world#a-diplomacy-web). |
| **Draft** | Two things. The first stage of the default workflow. A canon status, the one a new note has. See [Workflow](/docs/settings/project#workflow) and [Canon status](/docs/canon#canon-status). |

## E

| Term | What it means |
| --- | --- |
| **Editor** | Two things. The page a note opens in. Also a project role: someone who can read, comment and edit in one project. See [The editor](/docs/writing/editor) and [The roles](/docs/reference/roles-and-permissions#the-roles). |
| **Element** | Two things. A line of a script with a job: scene heading, action, character, dialogue. In the Production module, a thing a scene needs, such as a prop, tagged in the text. See [Writing in a script](/docs/modules/scripts#writing-in-a-script) and [Tagging an element](/docs/modules/production#tagging-an-element). |
| **Embed** | Another note shown inside the one you are writing, live and read-only, made by typing `![[`. See [Embeds](/docs/writing/links#embeds). |
| **Entity type** | See **World entry**. |
| **EPUB** | The e-book the Publish view builds from the manuscript. See [EPUB](/docs/modules/publishing#epub). |
| **Event** | Something on a timeline that is not a scene: a war, a birth. It belongs to that timeline only. **Event** is also one of the starting world-entry types. See [Events](/docs/views/timeline-and-canvas#events). |
| **Export** | Taking text out as Word, rich text, Final Draft, Markdown, plain text, an outline, AO3 or PDF, or the whole project as a `.plotra` file. Export is never blocked by a plan limit. See [Export](/docs/import-export/export). |
| **Expression** | What a Condition or a Set card is written in: a small language of values, variables and operators, such as `gold >= 5`. See [The expression language](/docs/modules/interactive/expressions). |

## F

| Term | What it means |
| --- | --- |
| **Fact-check** | A status on a block that marks it as a claim: Unverified, Verified or Disputed, with the source it rests on. See [Fact-check status per claim](/docs/modules/research#fact-check-status-per-claim). |
| **Family tree** | A layout of the Relationships map that arranges characters in generations, from their "Parent of" and "Married to" relationships. See [A family tree](/docs/views/world#a-family-tree). |
| **Field** | See **Property**. |
| **Find a note** | Jump to a note by typing part of its name, opened with `⌘O`. It used to be called the quick switcher. See [Find a note](/docs/get-started/the-screen#find-a-note). |
| **Focus mode** | Hides the ribbon, the binder, the inspector and the status bar, leaving the pane you are writing in (`⌘⇧F`). See [Focus mode](/docs/writing/editor#focus-mode). |
| **Folder** | A kind of note for grouping. A folder has a page of its own and can stand for a book, an act or a season. See [Note types](/docs/writing/binder#note-types). |
| **Format** | See **Script format**. |
| **Fountain** | A plain-text format for screenplays that other screenwriting apps open. Plotra reads and writes it through two commands in **All commands**. See [Fountain](/docs/modules/scripts#fountain). |
| **Front matter** | Two things. The title page and other pages an export or an e-book can put before the text. In an imported Markdown file, the block of fields at its top, which becomes properties. See [Front matter pages](/docs/import-export/export#front-matter-pages) and [Front matter](/docs/import-export/import#front-matter). |

## G

| Term | What it means |
| --- | --- |
| **Getting started** | The checklist of five steps shown in a project that was started from the cold open. See [The getting-started checklist](/docs/get-started/first-project#the-getting-started-checklist). |
| **GitHub sync** | A copy of a project kept in a GitHub repository as Markdown files, updated a few minutes after each change. Set up in **Project settings → GitHub**, where **Copy now** sends waiting changes at once. See [A copy kept in GitHub](/docs/import-export/export#a-copy-kept-in-github). |
| **Glossary (localization)** | The project's term base: the official translation of each name and invented word in each language, and the words that must not be translated. It is a tab of the Translate view. See [The glossary](/docs/modules/localization#the-glossary). |
| **Goal** | A number of words to reach: a daily goal and a session goal, which are yours, and a project target, which is the project's. See [Goals](/docs/writing/goals#goals). |
| **Graph** | The view that draws every note as a dot and every link as a line, or lists them as text in its **List** mode. **Whole project** shows every note; **Around this note** (the local graph) shows one note and what is a few steps away from it. See [Graph](/docs/views/world#graph). |
| **Guest** | Someone a project is shared with who is not a member of its workspace. A guest sees only the projects shared with them. See [Guests](/docs/settings/account#guests). |

## H

| Term | What it means |
| --- | --- |
| **Horizon** | See **Spoiler horizon**. |
| **Hosted AI** | The agent running on a model Plotra provides, paid for with a Pro workspace's monthly credits, so nobody in the workspace needs a key. See [Hosted AI and credits](/docs/settings/plans#hosted-ai-and-credits). |
| **Hosted version** | Plotra as run for you at plotra.ink, with the Free and Pro plans. The other way to use Plotra is to host it yourself. See [How it differs from the hosted version](/docs/self-hosting#how-it-differs-from-the-hosted-version). |

## I

| Term | What it means |
| --- | --- |
| **Import** | Turning Markdown, Word, rich-text and plain-text files, a folder of them, or a Scrivener, Plottr or World Anvil project, into chapters, scenes and notes. A `.plotra` file is imported as a new project. See [Import](/docs/import-export/import). |
| **Inbox** | The tab of the Reviews view with the notes waiting for your approval, those in review and those locked. See [The Inbox](/docs/modules/editorial#the-inbox). |
| **Inline action** | An AI action on a passage in the editor: Continue writing, Rewrite, Shorten, Expand or Change tone. It changes nothing until you accept the result. See [In the editor](/docs/ai#in-the-editor). |
| **Inspector** | The sidebar on the right, about the note in the active tab. Its tabs are Note, Links, Story, Review and AI. See [The inspector](/docs/get-started/the-screen#the-inspector). |
| **Instance's key** | One AI model that whoever runs a self-hosted server gives everyone on it, so nobody needs a key of their own. See [The instance's key](/docs/ai/models-and-privacy#the-instances-key). |
| **Interface size** | How big the app's buttons, menus and labels are drawn, on every page: Compact, Comfortable, Large or Larger. Set in **Customize → Look**. The text you write has its own size. See [Interface size](/docs/settings/customize#interface-size). |
| **Invitation** | An emailed link that lets someone join a workspace as a member or an admin. It is good for 48 hours. See [Inviting people to the workspace](/docs/collaboration/sharing#inviting-people-to-the-workspace). |

## J

| Term | What it means |
| --- | --- |
| **Jump** | An arrow from one dialogue card to the next. See [Drawing jumps](/docs/modules/interactive/dialogue#drawing-jumps). |

## K

| Term | What it means |
| --- | --- |
| **Keep on this device** | Keeping every note of a project in this browser, so the whole project opens offline. The command says "Keep this project on this device, for offline". See [Keeping a whole project on this device](/docs/writing/editor#keeping-a-whole-project-on-this-device). |
| **Kind** | What sort of note something is: Folder, Chapter, Scene, Note, Character, Location, World entry, Research, Canvas, Timeline or Dialogue. The interface calls it the note's **type**: **Change type** in a note's menu changes it. It decides the note's icon, its fields and which view opens it. See **Note type** and [Note types](/docs/writing/binder#note-types). |
| **Knowledge layer** | Whether a note or a block is the **Truth**, or a **Belief**: a false version people are led to believe. Everything is truth until you say otherwise. See [Knowledge layers](/docs/canon/secrets-and-continuity#knowledge-layers). |

## L

| Term | What it means |
| --- | --- |
| **Label** | A coloured mark on a note, such as "Needs research", defined per project and separate from the note's status. A note carries one. The docs also say "colour label". See [Labels](/docs/settings/project#labels). |
| **Lane** | A row of a timeline. A timeline can be split into lanes by plot thread, by point-of-view character or by location. See [Lanes](/docs/views/timeline-and-canvas#lanes). |
| **Layer** | A named group of marks (pins, regions and paths) on a map. Unticking one hides it, for you only. See [Layers](/docs/views/maps#layers). |
| **Layout** | An arrangement of open tabs and split panes, saved under a name so you can switch back to it. The interface says **Saved layouts**. See [Saved layouts](/docs/get-started/the-screen#saved-layouts). |
| **Library** | A folder on your own computer where the desktop app keeps your projects, with a Markdown copy and snapshots beside them. No account and no internet. See [A library on this computer](/docs/desktop#a-library-on-this-computer). |
| **Limit** | A cap on room: projects, storage, members, guests. Limits belong to a workspace's plan on the hosted version. No limit locks a feature, deletes work or blocks export. See [Limits on the hosted version](/docs/settings/limits). |
| **Local mode** | Plotra running inside the desktop app on your computer, on a library: one person, nothing to share, no plans. See [What a library doesn't have](/docs/desktop#what-a-library-doesnt-have). |
| **Lock** | A note in a workflow stage ticked **Locked** is read-only for everyone but its approvers. The editor shows a **Locked** badge. See [Locked content](/docs/modules/editorial#locked-content). |
| **Long job** | A list of up to 40 steps the agent saves for work too long for one request, such as drafting an act. Nothing changes until you start it. See [Long jobs](/docs/ai#long-jobs). |

## M

| Term | What it means |
| --- | --- |
| **Manuscript** | Two things. The view that stitches a folder's notes into one long editable page; its command says "Read the whole draft". In export and publishing, "the manuscript" means the project's folders, chapters and scenes. See [Manuscript](/docs/views/planning#manuscript) and [What is included](/docs/import-export/export#what-is-included). |
| **Map** | A kind of canvas made from a picture of your world, with pins, regions and paths that link to notes. See [Maps](/docs/views/maps). |
| **MCP** | The Model Context Protocol. Plotra is an MCP server, so an AI assistant such as Claude or Cursor can read your projects and write into them with your API token. See [MCP server](/docs/developers/mcp). |
| **Member** | A workspace role. A member can open, write in and comment on every project in the workspace and start new ones. "Member" is also used for anyone in the workspace, whatever their role. See [Members](/docs/settings/account#members). |
| **Mention** | Typing `@` and a name in a comment, which notifies that person. Workspace members and anyone the project is shared with who has accepted can be mentioned; guests are marked **Guest**. See [Mentions](/docs/collaboration/comments-and-suggestions#mentions). |
| **Mentioned here** | The list under a codex entry of the notes that link to it, each with the line the link is in. See [A shared world](/docs/views/world#a-shared-world). |
| **Mentioned in** | The notes that link to the note you have open, in the inspector's **Links** tab. Embeds, properties that point at the note and citations count as well. The docs used to call them backlinks. See [Mentioned in](/docs/writing/links#backlinks). |
| **Mode (Ask, Suggest, Auto)** | What the agent may do. **Ask** reads and changes nothing. **Suggest** makes text edits as suggestions and asks before anything else. **Auto** applies changes, and still asks before trashing and before changing canon status. See [The three modes](/docs/ai#the-three-modes). |
| **Module** | A set of views, commands and inspector sections that a project switches on when it needs them. The interface calls them **tools**: the **Tools** tab of the project settings switches them, and the ribbon's **More** menu calls the ones that are off **More tools**. There are ten. See [Modules](/docs/modules). |
| **More** | The ribbon menu that holds every view not pinned to your ribbon, the tools that are off, and a few switches. See [The More menu](/docs/get-started/the-screen#the-more-menu). |

## N

| Term | What it means |
| --- | --- |
| **"Never" passage** | A block tagged as never revealed to the audience. It is hidden under every spoiler horizon and left out of file exports, EPUB and the wiki. The read-only link and a PDF printed with no horizon still show it. See [Passages marked Never](/docs/canon/releases-and-reveals#passages-marked-never). |
| **Named but not linked** | Places where a note's name or alias appears as plain text without a link, in the inspector's **Links** tab. The docs used to call them unlinked mentions. See [Named but not linked](/docs/writing/links#unlinked-mentions). |
| **No AI** | A promise a workspace's owner can make that AI stays off: nobody can switch it on until the owner lifts it, and the workspace's home page says so. A self-hosted server can take AI out altogether. See [A promise of no AI](/docs/ai#a-promise-of-no-ai). |
| **Note** | Two things. Anything in the binder: every item is a note of some kind. Also one kind among them, **Note**, for anything that is not a scene, a character or another specific kind. See [Note types](/docs/writing/binder#note-types). |
| **Note template** | A note chosen as the template for its kind: every new note of that kind starts as a copy of its text, fields and tags. Not the same as a project template. See [A template for new notes](/docs/writing/binder#a-template-for-new-notes). |
| **Note type** | Two uses. What sort of note something is (see **Kind**). And a type of world entry you define yourself, such as a Faction or a Spell, made in the **Note types** tab of the project settings. See **World entry**. |
| **Notification** | A message addressed to you under the bell: a mention, a reply, a share, an accepted invitation, a review request or a review decision. See [The bell](/docs/collaboration/notifications#the-bell). |

## O

| Term | What it means |
| --- | --- |
| **Orphan** | The old name for **Unlinked notes**. |
| **Outline** | Two things. The view that shows every note as a row of a table, with properties as columns. Also a panel of the inspector that lists the open note's headings. See [Outline](/docs/views/planning#outline) and [The inspector](/docs/get-started/the-screen#the-inspector). |
| **Owner** | A workspace role. An owner can do everything an admin can, and also switches AI on or off for the workspace and manages the plan and billing. Whoever creates a workspace is its owner. See [Members](/docs/settings/account#members). |

## P

| Term | What it means |
| --- | --- |
| **Palette** | The set of colours the app is drawn in, also called a theme: one of Plotra's (Paper, Sepia, Slate, Forest, Pure, High contrast, Dusk, Fjord, Rosewood, Mocha), one from a plugin, or one you make, each light and dark. See [Colours and your own CSS](/docs/settings/customize#colours-and-your-own-css). |
| **Pane** | A part of the middle of the screen that holds tabs. Panes can be split right or down. See [Tabs and panes](/docs/get-started/the-screen#tabs-and-panes). |
| **Pin** | A point on a map that marks a place and can link to a note. Regions and paths are drawn the same way. See [Pins, regions and paths](/docs/views/maps#pins-regions-and-paths). |
| **Plan** | Free or Pro, on the hosted version. A plan belongs to a workspace, not to a person. A Plotra you host yourself has no plans. See [The plans](/docs/settings/plans#the-plans). |
| **Play-through** | Walking a dialogue from its Start card the way a game would, to test it. Nothing about it is saved. See [Playing a dialogue](/docs/modules/interactive/dialogue#playing-a-dialogue). |
| **Plot grid** | The view with scenes down the side and plot threads across the top. Each cell says what happens to that thread in that scene. See [Plot grid](/docs/views/planning#plot-grid). |
| **Plotra project file** | A `.plotra` file holding a whole project: every note, its history, comments, pictures and files, and its shared world. Importing it makes a new project. See [Plotra project files](/docs/import-export/import#plotra-project-files). |
| **Plugin** | A script of your own that adds commands, panels, export formats or kinds of world entry, run sandboxed in your browser with your access. See [Plugins](/docs/developers/plugins). |
