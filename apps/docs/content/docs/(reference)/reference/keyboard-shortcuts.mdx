Almost everything in a project can be done without the mouse. This page lists every command, the keys it starts with, and the keys the editor has built in.

The same list is in the app: press `⌘/`, or choose **Keyboard shortcuts** from **More** in the ribbon or from the user menu. The list in the app shows the keys as you have set them and only the commands this project has.

This page writes keys the way a Mac shows them. On Windows and Linux, use `Ctrl` for `⌘` and `Alt` for `⌥`; the app shows them as `Ctrl+Shift+P`.

## How shortcuts work

- A command's shortcut works anywhere in the project, including while you are typing in the editor.
- A shortcut that has neither `⌘` nor `⌥` in it, apart from the function keys, is ignored while you are typing in a text box, so a key you bind on its own doesn't get in the way of writing.
- Every command is also in **All commands** (`⌘P`), with its current keys beside it. A command without keys can still be run from there.
- Some shortcuts are also used by the browser. `⌘P` is the browser's Print and `⌘O` its Open; inside a project, Plotra takes them.
- Others the browser keeps for itself, such as `⌘T`, `⌘W`, `⌘⇧R` (reload) and `⌘⇧C` (the element picker). A page never hears them, so no command starts with one, and you can't give one to a command.

## Changing a shortcut

1. Press `⌘/` to open **Keyboard shortcuts**.
2. Find the command, or the formatting key under **Formatting**. The search box matches the name, the group, or the keys, typed as shown (`⌘P`) or spelled out (`mod+p`).
3. Click the keys at the right of its row (or **None**, if it has no shortcut). The row shows "Press keys…".
4. Press the new combination.

![The Keyboard shortcuts dialog searched for "format": the Formatting group, from Bold to New paragraph below the block, each with its keys](/shots/keyboard-shortcuts.webp)

| While it says "Press keys…" | What happens |
| --- | --- |
| Any combination | Becomes the command's shortcut. If another command has it, Plotra asks first ("‘⌘G’ is already used"); **Use it here** moves it, and the other command is left with none. |
| A combination the browser keeps | Refused, with "Your browser keeps … for itself, so it won't reach Plotra. Try another." |
| `⌫` or `Delete` | Removes the shortcut. The command shows **None**. |
| `Esc` | Cancels. |

A row you have changed shows a reset button ("Put … back to its default shortcut"), which gives it back the keys it started with.

The rows under **Editor (fixed)** can't be changed. The formatting keys (bold, italic, headings, quote, new paragraph above or below) can: they are under **Formatting**.

The **Like Scrivener** and **Like Obsidian** presets in **Customize** change a few shortcuts for you. See [Work like another app](/docs/settings/customize#work-like-another-app).

### Where changed shortcuts are stored

Changed shortcuts are stored with your account, so they follow you to every project, browser and computer. Shortcuts changed before they were kept in the account are moved there the first time you open a project in that browser. **Customize** → **Keyboard shortcuts** resets them all at once.

`⌘⌥N` makes the project's main type of note: the first one in the binder's **New** menu. If the project has its own names for the note types, the commands use them: "New session" in place of "New chapter". "This note" is the note in the active tab, or the one selected in the binder if no note is open, and **All commands** names it by its type: "Rename this chapter".

With the binder itself focused, these keys work as well. They are fixed.

| Keys | What it does |
| --- | --- |
| `↑` `↓` | Move the selection |
| `Home`, `End` | Go to the first or the last note |
| `→` | Open a folder, then go to its first note |
| `←` | Close a folder, then go to its parent |
| `↵` or `Space` | Open the note, or open and close a folder |
| `⌘↵` | Open the note in a new tab |
| `⌘⌥↵` | Open the note to the right |
| `F2` | Rename the note |
| `⌥↑` `⌥↓` | Move the note up or down among its neighbours |
| `⌥→` | Move the note into the one above it |
| `⌥←` | Move the note out of its folder |
| `⇧F10` or the menu key | Open the note's menu, as right-click does |
| `Delete`, or `⌘⌫` | Move the note to the trash, with **Undo** |
| A letter or a digit | Jump to the next note whose name starts with it |
| `Esc` | Clear the binder's **Filter…** box |

`⌫` on its own no longer trashes a note: it is too easy to press by accident.

With the mouse: click opens a note in the current tab, `⌘`-click or middle-click in a new tab, and `⌘⌥`-click to the right. The same goes for a link in the text. See [Working in the binder](/docs/writing/binder#working-in-the-binder).

### Selected blocks

Click a block's handle in the margin to select the whole block. Then:

| Keys | What it does |
| --- | --- |
| `↑` `↓` | Select the block above or below instead |
| `⇧↑` `⇧↓` | Add the block above or below to the selection |
| `⌘A` | Select every block in the note |
| `⌘D` | Duplicate the selected blocks |
| `⌘C`, `⌘X` | Copy or cut them |
| `⌫` or `Delete` | Delete them |
| `⌘⌥T` | Tag them all |
| `↵` | Put the cursor back in the text, at the end of the block |
| `Esc` | Clear the selection |

See [Moving blocks](/docs/writing/editor#moving-blocks).

### Typed in the text

| Type | What it does |
| --- | --- |
| `/` | Opens the block menu |
| `[[` | Links to a note (unless **A list of notes on [[** is off in Customize) |
| `[[Note#` | Links to a heading in a note |
| `[[Note\|words` | Links to a note, showing other words |
| `![[` | Embeds a note |
| `#name` | Tags the note |
| `#`, `##`, `###` and a space | Heading 1, 2, 3 |
| `-` or `*` and a space | Bulleted list |
| `1.` or `1)` and a space | Numbered list |
| `[ ]` or `[x]` and a space | To-do, open or ticked |
| `>` and a space | Quote |
| `---` or `___` | Divider |
| `**text**` | Bold |
| `*text*` or `_text_` | Italic |
| `***text***` | Bold and italic |
| `~~text~~` | Strikethrough |
| `==text==` | Highlight |
| `` `text` `` | Inline code |

| `--` | Em dash |
| `...` | Ellipsis |
| `->` | Arrow |
| `(c)` | Copyright sign |

Straight quotes become curly ones as you type. With the **Research & sources** module on, `[@` starts a [citation](/docs/modules/research#citations-in-the-editor). **Markdown as you type**, **Smart quotes and dashes** and the list on `[[` can each be switched off in **Customize → Typing**.

### In a script

In a note written in a script format, `Tab` and `Shift+Tab` change the element the line is: scene heading, action, character, dialogue. `^` at the end of a character name marks its speech as [dual dialogue](/docs/modules/scripts#dual-dialogue), set beside the one before. See [Scripts](/docs/modules/scripts).

The editor's blocks, toolbar and menus are described on [The editor](/docs/writing/editor).

| --- | --- | --- |
