Welcome to Plotra

Where should your work live?

You can change this later from the File menu, and use both. Projects in the cloud and in a library are kept separately.

Plotra Cloud

  • Your Plotra account, the same projects as on the web
  • Write with others, share, and sync between devices
  • Backups and hosted AI

On this computer

  • No account, no internet needed
  • Everything in a folder you choose: a library
  • Only you. Backed up once a day, inside the folder

Recent libraries

Signing in happens in your browser, where your password manager and Google sign-in work. On this computer, AI works with your own key, or a model that runs on your computer.

Set up your library

A library is a folder on this computer that holds your projects. You can make more later, from the File menu.

Where

  • Your projects, in a database that Plotra opens
  • A Markdown copy of every project, readable in any app
  • A snapshot of everything whenever you choose File → Back Up Now

Back it up like any folder. If it's in iCloud Drive or Dropbox, close Plotra on one computer before you open the library on another.
